# ckty-hub

A script hub aiming for quality scripts instead of quantity.

## Usage

For latest release
```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/CioKiTTY/ckty-hub/main/loader.luau"))()
```

Specific version
```lua
getgenv().CKTY_HUB_VERSION = "v0.0.1-unstable.1"

loadstring(game:HttpGet("https://raw.githubusercontent.com/CioKiTTY/ckty-hub/" .. getgenv().CKTY_HUB_VERSION .. "/loader.luu"))()
```
